# 음력 변환 독립 검증

앱의 음력 변환(`korean-lunar-calendar` 기반, `src/lib/lunar.ts`)을 **천문 계산으로 따로 산출한 한국 음력**과 날짜별로 대조합니다.

`astro.py`는 다음 규칙으로 한국 음력을 계산합니다 (한국천문연구원과 같은 방식).
- 삭(朔, 합삭)이 든 **한국 표준시(KST) 날짜**가 매월 1일 (1954-03-21~1961-08-09는 UTC+8:30)
- 태양 겉보기 황경이 30°의 배수가 되는 **중기**로 월 번호 결정 (동지가 든 달 = 11월)
- 동지월~다음 동지월이 13개월이면 **중기가 없는 첫 달이 윤달**

```bash
pip install ephem
python3 astro.py 1950 2050 astro.txt   # 연-월-일 음력월 음력일 윤달여부
```
앱 쪽 결과와 비교하려면 `solarToLunar`를 같은 범위로 돌려 같은 형식으로 덤프한 뒤 diff 하세요.
결과(2026-11 기준): 1950-01-01~2050-12-31, 36,890일 **불일치 0건**, 윤달 37개 동일.
정밀도 점검: 2026 춘분/하지, 2025 동지 시각을 20초 이내로 재현.

`__tests__/fixtures/lunar-anchors.json`은 이 계산으로 만든 2000~2050년 설날·추석·부처님오신날·윤달 시작일입니다.
